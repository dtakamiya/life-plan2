# FP一級ライフプランニングWebアプリ

FP一級レベルのライフプランニング機能を提供するWebアプリケーションです。将来の資産形成、退職後の生活設計、税務計算などをシミュレーションできます。

## 機能

- **基本情報管理**: ユーザー情報、家族構成の入力
- **収入・支出管理**: 年収、ボーナス、各種支出の管理
- **資産・負債管理**: 現金、株式、不動産などの資産とローン残高の管理
- **保険情報**: 生命保険、医療保険などの保険情報の管理
- **ライフイベント**: 結婚、出産、教育費、住宅購入などの将来イベントの設定
- **シミュレーション**: 
  - 将来の資産推移の予測
  - 退職後の生活費シミュレーション
  - 税務計算（所得税、住民税、相続税）
  - 年金受給額の計算
- **可視化**: グラフ・チャートによる資産推移の可視化

## セットアップ

### バックエンドの起動

```bash
cd backend
poetry install
poetry run uvicorn app.main:app --reload --port 8000
```

### フロントエンドの起動

```bash
cd frontend
npm install
npm run dev
```

## 使い方

1. ブラウザで `http://localhost:5173` を開く
2. タブを切り替えて、以下の情報を入力：
   - **基本情報**: 名前、生年月日、性別、配偶者情報
   - **収入**: 年収、ボーナス、退職予定年齢
   - **支出**: 生活費、住宅費、教育費、保険料など
   - **資産**: 現金、株式、債券、不動産など
   - **保険**: 加入している保険の情報
   - **ライフイベント**: 将来の予定されているイベント
3. 「シミュレーション実行」ボタンをクリック
4. 結果画面で以下を確認：
   - 退職時の資産額
   - 年金不足額
   - 年齢別の資産推移グラフ
   - 収支推移グラフ
   - 詳細な年次データ

## APIエンドポイント

### POST `/api/life-plan/simulate`
ライフプランのシミュレーションを実行

**リクエストボディ:**
```json
{
  "profile": {
    "name": "山田太郎",
    "birth_date": "1980-01-01",
    "gender": "male"
  },
  "income": {
    "annual_salary": 600,
    "bonus": 100,
    "retirement_age": 65
  },
  ...
}
```

### POST `/api/tax/inheritance`
相続税を計算

**パラメータ:**
- `assets`: 資産額（万円）
- `heirs`: 相続人数（デフォルト: 1）

## 注意事項

- 本アプリケーションは簡易的な計算を行っています。実際のFP一級試験や実務では、より詳細な計算が必要です
- 税務計算は簡易版です。実際の税務申告では、税理士やFPにご相談ください
- 年金計算も簡易版です。正確な受給額は日本年金機構にご確認ください
