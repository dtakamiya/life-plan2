# FP1級レベル ライフプランナー

FP（ファイナンシャルプランナー）1級レベルの包括的なライフプランニングを提供するWebアプリケーションです。

## 🌟 機能

### 基本情報入力
- 個人プロファイル（年齢、性別、職業、婚姻状況など）
- 家族構成（配偶者、子供、親など）
- 年収、ボーナス、定年退職年齢設定

### 資産・負債管理
- 資産（現金・預金、株式、投資信託、債券、不動産など）
- 負債（住宅ローン、自動車ローン、教育ローンなど）
- 純資産の自動計算

### 支出管理
- 月間支出の詳細入力（住居費、食費、光熱費など）
- 支出構成の可視化
- 収入に対する支出比率の分析

### ライフイベント計画
- 結婚、出産、住宅購入、車購入など
- イベント別の費用計画
- タイムライン表示

### 保険設計
- 必要保障額の計算（遺族生活資金法）
- 現在の保障額との比較
- 医療保険、がん保険、就業不能保険の管理

### 資産運用シミュレーション
- 積立投資シミュレーション（複利計算）
- リスク許容度に応じた期待リターン設定
- NISAやiDeCoの節税効果計算

### 年金シミュレーション
- 老齢基礎年金の試算
- 老齢厚生年金の試算
- iDeCo拠出額管理

### ライフプラン診断
- 生涯キャッシュフロー分析
- 資産推移グラフ
- リスク評価と改善提案
- 税金・社会保険料計算

## 🛠️ 技術スタック

### フロントエンド
- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui（UIコンポーネント）
- Recharts（グラフ表示）
- React Hook Form + Zod（フォームバリデーション）

### バックエンド
- Python 3.12
- FastAPI
- Pydantic

## 🚀 セットアップ

### 必要要件
- Node.js 18+
- Python 3.12+

### フロントエンド

```bash
cd frontend
npm install
npm run dev
```

開発サーバーが `http://localhost:5173` で起動します。

### バックエンド

```bash
cd backend
pip install fastapi[standard] uvicorn
uvicorn app.main:app --reload
```

APIサーバーが `http://localhost:8000` で起動します。

## 📖 使い方

1. **サンプルデータ読込**: 「サンプルデータ読込」ボタンをクリックすると、サンプルプロファイルが自動入力されます
2. **基本情報入力**: 年齢、収入、家族構成などを入力
3. **資産・負債入力**: 現在の資産と負債を入力
4. **支出入力**: 月間の支出項目を入力
5. **ライフイベント追加**: 将来の予定を追加
6. **保険情報入力**: 現在加入している保険情報を入力
7. **投資・年金入力**: 資産運用計画と年金情報を入力
8. **診断実行**: 「ライフプラン診断を実行」ボタンをクリック
9. **結果確認**: 診断結果、グラフ、改善提案を確認

## 📊 API エンドポイント

| エンドポイント | メソッド | 説明 |
|---------------|---------|------|
| `/api/life-plan` | POST | ライフプラン診断実行 |
| `/api/tax-calculation` | POST | 税金計算 |
| `/api/pension-simulation` | POST | 年金シミュレーション |
| `/api/housing-loan` | POST | 住宅ローン計算 |
| `/api/investment-simulation` | POST | 投資シミュレーション |
| `/api/education-cost` | POST | 教育費計算 |
| `/api/life-events/templates` | GET | ライフイベントテンプレート取得 |
| `/api/sample-profile` | GET | サンプルプロファイル取得 |
| `/healthz` | GET | ヘルスチェック |

## ⚠️ 免責事項

このツールは参考情報を提供するものであり、具体的な金融・税務アドバイスではありません。
重要な決定の際は、必ず専門家（ファイナンシャルプランナー、税理士など）にご相談ください。

計算結果は2024年度の法令・税率に基づいており、将来の制度変更により異なる場合があります。
